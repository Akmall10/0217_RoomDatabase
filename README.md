# 0217_RoomDatabase - Aplikasi Data Siswa

Aplikasi Android untuk mengelola Data Siswa menggunakan Room Database, ViewModel, dan Jetpack Compose.

## 📱 Fitur Aplikasi
- Menampilkan daftar siswa
- Menambah data siswa baru (Nama, Alamat, Nomor Telepon)
- Penyimpanan data lokal menggunakan Room Database
- Arsitektur MVVM (Model-View-ViewModel) dengan Repository Pattern

## 🛠️ Teknologi & Library
- Kotlin
- Jetpack Compose (Material 3)
- Room Database
- Navigation Compose
- StateFlow & Coroutines
